# CMS Sylius integration

- Add CMS content, routes, blocks, menus, media, and optional sections to the Sylius admin navigation.
- Provide Sylius-specific Twig overrides for CMS and media administration.
- Load CMS collection translations into the Sylius theme translation provider, including projects with empty element directories.
- Publish browser assets for Symfony AssetMapper when it is available.

The bundle integrates an installed CMS with Sylius. Applications still configure their routes, permissions, sites, media storage, and content definitions.
